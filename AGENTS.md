# Repository instructions

For every planning, implementation, review, debugging, architecture, dependency, configuration, deployment, Jira-stage, or documentation task in this repository:

1. Read `.codex/skills/maintain-project-context/SKILL.md`.
2. Follow it and load both project-context references before acting.
3. Update the project snapshot in the same change whenever current requirements, stack, configuration, interfaces, roadmap status, or deployment assumptions change.
4. Append every accepted architecture decision and every material project change to the ADR/change log. Never rewrite accepted ADR history; supersede it.
5. Never place secrets, private credentials, cookies, Telegram initData, or sensitive environment values in project documentation or ADRs.
